# Changelog

All notable changes to this plugin. Versions match `version` in

- Initial release: `session-recall` skill (export, quiz runner, folder config),

  quiz runner.
- Packaged as a Claude Code plugin, listed in the `gritee` marketplace
  ([Gritee/claude-plugins](https://github.com/Gritee/claude-plugins)).
